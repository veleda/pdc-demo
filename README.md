# From DataFrame to KnowledgeGraph in 4 lines of Python

As demoed at the lunch & learn at PDC Jun 8, 2026. 

#### Content
* Supershort demo: 4 lines of Python
* demo: ETLT with three data sources; data frames, RDF, SPARQL <3
* demo extended: building on the demo, harvesting more data from Discogs over API (need API key, get for free at [discogs.com/settings/developers](discogs.com/settings/developers))
